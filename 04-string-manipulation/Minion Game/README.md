# The Minion Game

## Problem Overview

The Minion Game is a string manipulation challenge from HackerRank.

Given a string, two players, Kevin and Stuart, create substrings from the original string.

- Kevin scores points for substrings starting with vowels.
- Stuart scores points for substrings starting with consonants.
- Each occurrence of a substring contributes one point.

The player with the highest score wins.

## Concepts Practiced

- Python string manipulation
- String indexing and slicing
- Loops and iteration
- Algorithmic problem-solving
- Efficient counting techniques
