## 🗂️ Repository Structure

The repository is organized into progressive learning sections, moving from fundamental programming concepts toward scientific computing and data-oriented applications.

| Directory | Description |
|---|---|
| `01-python-fundamentals` | Variables, data types, operators, conditions, loops, and functions |
| `02-data-structures` | Lists, tuples, dictionaries, sets, and fundamental data structures |
| `03-algorithms` | Problem-solving techniques, searching, sorting, and algorithmic thinking |
| `04-numpy` | Numerical computing, multidimensional arrays, and vectorized operations |
| `05-pandas` | Data manipulation, cleaning, transformation, and analysis |
| `06-data-visualization` | Data visualization and graphical representation using Python |
| `07-scientific-computing` | Mathematical and computational methods using Python |
| `08-machine-learning` | Foundations and practical implementations of Machine Learning |
| `09-computer-vision` | Image processing and introductory Computer Vision projects |
