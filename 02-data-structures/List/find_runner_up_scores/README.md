
# Find the Runner-Up Score

## Problem Overview
Given a list of participant scores, find and print the runner-up score (the second-highest unique score).

## Concepts Covered
- Python Lists
- List Manipulation
- Sets and Duplicate Removal
- Sorting
- Conditional Logic

## Approach
1. Read the number of participants.
2. Store their scores in a list.
3. Remove duplicate scores using a set.
4. Sort the unique scores in descending order.
5. Print the second-highest score.

## Example

**Input:**
```text
5
2 3 6 6 5
```

**Output:**
```text
5
```

## Complexity Analysis
- Time Complexity: O(n log n)
- Space Complexity: O(n)
